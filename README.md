# 三个村庄：第二人生 — SillyTavern 前端扩展

这是“三个村庄：第二人生”的浏览器端扩展。它必须与服务端插件配套使用。

## 安装

在 SillyTavern 中打开“扩展”→“安装扩展”，粘贴：

    https://github.com/nanjun434-byte/trio-second-life-ui

安装完成后刷新页面。

服务端插件安装说明：<https://github.com/nanjun434-byte/trio-second-life-server>
